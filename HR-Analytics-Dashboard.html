Methodology

🧮 Flight Risk Algorithm

score = 0 if OverTime == 'Yes': score += 2 if JobSatisfaction <= 2: score += 2 if WorkLifeBalance <= 2: score += 2 if YearsLastPromotion >= 3: score += 1 if DistanceFromHome >= 20: score += 1 # Score 6–8 → 38% attrition · Score 0–1 → 6.7%

📊 Burnout Index

burnout = 0 if OverTime: burnout += 3 if WorkLifeBalance <= 2: burnout += 3 if JobSatisfaction <= 2: burnout += 2 if EnvironmentSatisfaction <= 2: burnout += 1 if JobInvolvement <= 2: burnout += 1 # Max = 10 · High burnout ≥ 7

📈 Survival Analysis

Kaplan-Meier estimator applied to tenure data. At each time point t, S(t) = S(t-1) × (1 − d/n) where d = departures and n = employees at risk. Stratified by department.

💲 Compa-Ratio

compa = employee.income / avg_income_for_same_role # < 0.85 = underpaid vs peers # Danger Zone: compa < 0.85 AND perf_rating = 4

Diversity, Equity & Manager Effectiveness

Inclusion and structural analysis
⚖️
Promotion equity looks broadly balanced — but manager tenure has a massive impactMale and female promotion timelines are near-identical across departments. However, employees with managers in their first year leave at 28.3% — nearly 7× the rate of those with 10+ year managers (4.1%).
Promotion velocity by gender
Avg years since last promotion — Male vs Female
No significant gap detected in promotion timing between genders across all three departments. Male and female employees are promoted at near-identical rates within the same roles.
Attrition rate by gender
Does attrition differ by gender?
Attrition rates are similar across genders: Male 17.0% vs Female 14.8%. The gap is modest and does not indicate a systemic retention disparity by gender.
Manager tenure vs team attrition
Manager effectiveness — how long a manager has been in role affects their team's attrition rate significantly
The single most impactful structural finding: employees whose current manager has been in role for 0–1 years leave at 28.3%. Those whose manager has been in role for 10+ years leave at just 4.1%. Manager continuity — not just manager quality — is a retention anchor. This suggests that manager succession planning and handover quality are critical HR levers.
